# PyData Book Practice (3rd Edition)

Этот репозиторий содержит практические решения, код и Jupyter Notebooks по книге **«Python for Data Analysis» (3rd Edition)** Уэса Маккинни (Wes McKinney).

## 📌 Особенности
* Проработаны все основные главы книги (с 4 по 13).
* Код адаптирован под современные версии **Pandas 2.x** и **Python 3.12+** (исправлены устаревшие методы, такие как поведение `groupby.apply`, `include_groups`, устаревшие параметры `.map()` и `.idxmax()`).

## 🛠 Технологический стек
* **Language:** Python
* **Data Processing:** pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Modeling & Stats:** Statsmodels, scikit-learn
* **Environment:** Jupyter Notebook, PyCharm / VS Code

## 📁 Структура репозитория

* `chapter_04_numpy_basics/` — Основы NumPy: массивы и векторные вычисления
* `chapter_05_pandas_intro/` — Введение в структуры данных Pandas (Series, DataFrame)
* `chapter_06_data_loading/` — Загрузка данных, чтение и запись файлов разного формата
* `chapter_07_data_cleaning/` — Очистка, подготовка данных, обработка пропусков и дубликатов
* `chapter_08_data_wrangling/` — Преобразование данных: соединение, объединение, изменение формы (reshape)
* `chapter_09_visualization/` — Визуализация данных с помощью Matplotlib и Seaborn
* `chapter_10_data_aggregation/` — Агрегирование данных и групповые операции (Groupby)
* `chapter_11_time_series/` — Анализ временных рядов (Time Series)
* `chapter_12_modeling_libraries/` — Введение в моделирование: Statsmodels и scikit-learn
* `chapter_13_data_examples/` — Практические кейсы и анализ реальных датасетов (USA.gov, MovieLens, Baby Names, FEC Election Data)
* `datasets/` — Исходные наборы данных для выполнения упражнений
